# IT Helpdesk Ticketing System

A simple web-based IT helpdesk application built with Python, Flask and SQLite to manage and track IT support tickets.

## Features

- Create tickets with issue descriptions, requester details and priority levels.
- View ticket statistics on a dashboard.
- Update ticket statuses: Open, In Progress and Resolved.
- Store ticket data in an SQLite database.

## Technologies

Python · Flask · SQLite · SQL · HTML · CSS

## Setup

**1. Clone the repository**

```bash
git clone https://github.com/habib1712/Helpdesk-Ticketing-system.git
cd Helpdesk-Ticketing-system
```

**2. Create and activate a virtual environment**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**3. Install dependencies**

```powershell
python -m pip install -r requirements.txt
```

**4. Run the application**

```powershell
python app.py
```

Open http://127.0.0.1:5000 in your browser.
